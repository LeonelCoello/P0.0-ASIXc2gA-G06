# Infraestructura: aplicacion


Esta carpeta conserva los procedimientos y cambios del componente `aplicacion`. La descripción de cada sprint debe incluir: punto de partida, cambios ejecutados, comandos relevantes sin secretos, configuración validada, incidencias, capturas y enlace a pruebas. Se distinguen cambios completados de cambios previstos.

Los resultados transversales de gestión se registran en `sprints/`, no se duplican aquí.
