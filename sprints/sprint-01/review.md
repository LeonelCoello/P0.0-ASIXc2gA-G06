# Revisión de Sprint 1 — Finalizado

## Objetivo conseguido
Se construyó un MVP funcional de EducaBCN en una única instancia EC2 Ubuntu Server, con Apache, PHP, MySQL y una interfaz web que presenta un listado de centros educativos de Barcelona.

## Entregables constatados
- Repositorio Git y tablero de seguimiento.
- Instancia EC2 y acceso SSH.
- Instalación y comprobación de Apache y PHP.
- Instalación de MySQL y creación de la base EducaBCN.
- Importación inicial de 2.710 registros de OpenData BCN.
- Portal `index.php` que consulta y presenta datos de MySQL.

## Evidencias
Ver `media/sprint-01/`, la documentación de `infrastructure/` y las pruebas del catálogo.

## Limitaciones identificadas
Todos los servicios dependen de una sola máquina. No existe aislamiento entre web y datos. Se acuerda separar roles durante el Sprint 2.

## Cierre
La documentación original incluye la reunión de cierre del 27 de octubre de 2026, en la que se indica que se revisó la aplicación y la documentación, y se consideró terminado el Sprint 1.
